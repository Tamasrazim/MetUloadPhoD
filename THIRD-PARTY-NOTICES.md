# Third-party notices

## FFmpeg / FFprobe

Windows release builds bundle `ffmpeg.exe`, `ffprobe.exe`, and the runtime DLLs from the Gyan.dev FFmpeg Essentials build distribution:

- Distribution: https://www.gyan.dev/ffmpeg/builds/
- FFmpeg project: https://ffmpeg.org/
- FFmpeg license information: https://ffmpeg.org/legal.html

The exact component configuration and applicable LGPL/GPL notices are those supplied by the selected Gyan.dev build. The build workflow downloads the current `ffmpeg-release-essentials.zip`; consult the included build's license files and `ffmpeg -L` output for the exact configuration used by a particular release.
